### 🛡️ Engineering Philosophy & Hardening Standards

- **Zero Dummy Security:** Industry-grade cryptography by default: **AES-256-GCM** with fresh random nonces, key derivation via **PBKDF2 with ≥100,000 iterations**, anti-CSRF origin checks, anti-DNS-rebinding protection, and strict localhost (`127.0.0.1`) binding.
- **Radically Lean & Native:** No 300+ MB Electron containers. Built in pure **Go with WebKitGTK / Win32 API**, starting in milliseconds and consuming only 10–15 MB RAM.
- **100% Local-First & Zero AI Bloat:** No forced cloud logins, zero untracked telemetry, and zero artificial "AI assistants" shoved into offline tools.
- **Free Software & SemVer Integrity:** Licensed under the **GNU General Public License v3.0 (GPL-3.0)**. Strict SemVer tagging without trailing zeros (e.g. `v1.6`, `v2.1`), automated CI/CD multi-platform builds, and public web documentation.
