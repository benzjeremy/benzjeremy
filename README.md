**Gerade dabei:**

Keine Electron-App, kein Browser-Wrapper. GTK3, WebKitGTK, lokale SQLite-Datenbank, Microsoft OneDrive Sync mit AES-256-GCM, OAuth2 — und das alles in einer einzigen Binary.
